# EchoMuse on the Echo Show 8 (`crown`): Tier 2, recommended but optional
# (docs/echo-show-crown.md §9.2). Hidden only when the operator ticks it in
# the provisioning wizard's Neutralise Alexa step (off by default), and then
# re-asserted by start_server.sh at every boot alongside Tier 1.
#
# These free memory and stop Amazon's cloud, telemetry and radio use. None of
# them can take the microphone, the speaker or the screen; that is Tier 1.
# Apply Tier 2 once a Tier 1 baseline has passed §9.4 on the device: the
# Show's own Wi-Fi and Bluetooth (Android's WifiService and
# com.android.bluetooth, configured from the device's Settings) must still
# join a network and pair afterwards.
#
# Same mechanism and undo as Tier 1: `pm hide`, reversed by
# `pm unhide <package>`. Running the wizard again with Tier 2 unticked unhides
# this list.
#
# One package per line; lines starting with # are comments. Package names
# are this build's (NS65741/8146, `pm list packages -u`); the findings name
# some as families (com.amazon.device.smarthome.*, com.amazon.whisperjoin.*).
# Adding a package means repeating §9.4's verification on a device first.
